# 30 Hari Amal Terbaik — Muslim Habit Tracker

PWA Muslim Habit Tracker untuk tracking ibadah & amalan harian 30 hari.

## Live App
https://moslem-tracker-30days.netlify.app

## Fitur
- Checklist 8 grup ibadah harian
- Sistem skor & streak
- Notifikasi jadwal shalat (GPS)
- Notifikasi pengingat ibadah otomatis
- Do'a-do'a dari Al-Qur'an (unlock 30 poin/hari)
- Tracker 30 hari dengan grafik
- PWA — bisa install di HP

## Build APK
APK di-build otomatis via GitHub Actions setiap push ke `main`.
Download APK dari tab **Actions** → pilih workflow terbaru → **AmalTracker-v1.0-APK**
